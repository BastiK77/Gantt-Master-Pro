Gantt Master Pro – Dynamic Resource & Tour SchedulerThis project is a high-performance, web-based Gantt chart designed for coordinating teams, tools, and projects. Powered by a dual-canvas engine, it provides smooth rendering and three specialized planning modes:Yearly View (Strategic): Provides a long-term overview of the entire year. Perfect for high-level capacity planning and long-term project phases.Monthly View (Operational): A detailed daily view within a specific month. Features include weekday headers, grid lines, and highlighted weekends for precise task management.Tour View (Logistical): A focused 3-day rolling schedule. Key feature: Tasks on the same day are automatically stacked vertically (Smart Stacking). Bars span the full width of the day column and display precise start/end times directly on the label.Technical Features:ID-Based Persistence: Tasks are linked via unique resource IDs – no data misalignment when reordering or changing teams.Interactive UI: Drag & Drop to move, edge resizing, Shift + Drag to create new tasks, and Ctrl + Drag for instant copying.Team Hierarchy: Dynamic tree structure with connecting lines to visualize team assignments.Local Storage: Automatic data persistence saved directly within the browser.
